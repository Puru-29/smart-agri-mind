# AgriSense Insights Hub

Build the AgriSense Market Intelligence web application based on the attached screenshots. Replicate the visual style accurately: warm cream background, deep forest green primary accents, elegant serif headings, clean rounded cards, and badges. Implement the complete landing page (Hero, Why market information alone isn't enough, AI Decision Engine comparison cards, Market Intelligence features, 3-step workflow, Buyer Trust & FPO Aggregation, CTA and footer), as well as the authenticated portal with sidebar navigation including the Farmer Dashboard (/dashboard with active lot summary, AI decision banner, metrics, crop lots, market opportunities, and buyer opportunities) and the My Crops page (/crops with active crop lot cards and statuses). Support interactive states, tabs, and navigation between views.
